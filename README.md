# 🎮 摸鱼小游戏库

一个基于 React + TypeScript + Vite 构建的在线小游戏合集，包含 **574 款游戏**，涵盖益智、竞技、音乐、策略、模拟经营等多个类别。

## ✨ 特性

- 🎯 **海量游戏**: 574 款小游戏，49 个品类（首页 50 个分类入口）
- 🏷️ **元数据筛选**: 每款游戏带简介、标签、单局时长、难度、人数与键盘支持信息
- 🎯 **合集专题**: 按「双人同屏 / 5 分钟一局 / 纯键盘 / 静音可玩」自动聚合
- 📱 **响应式设计**: 支持桌面端和移动端
- 🎨 **霓虹风格**: 炫酷的霓虹色彩主题
- 💾 **本地存储**: 自动保存游戏进度和最高分
- ⚡ **流畅体验**: 基于 Canvas 渲染，性能优秀

### 合集专题

首页右上角的「合集专题」按摸鱼场景自动聚合游戏，数据来自游戏元数据：

- 👥 **双人同屏**：支持一台电脑两人玩的合作/对战游戏
- ⏱️ **5 分钟一局**：单局时长不超过 5 分钟的轻量游戏
- ⌨️ **纯键盘**：不动鼠标也能玩，适合假装在打字
- 🔇 **静音可玩**：不开声音也不影响体验

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite 6
- **样式**: TailwindCSS 3
- **动画**: Framer Motion
- **渲染**: Canvas API
- **状态管理**: React Hooks + localStorage

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 📁 项目结构

```
src/
├── components/          # 通用组件（背景、更新日志等）
├── games/               # 574 个游戏目录，单文件游戏为 <Name>/<Name>.tsx
├── pages/
│   ├── Home.tsx         # 首页：分类筛选 + 游戏卡片
│   ├── Game.tsx         # 游戏页：按 id 动态加载游戏组件
│   ├── Collections.tsx  # 合集专题页
│   └── UpdateLogPage.tsx
├── utils/
│   ├── constants.ts     # GAMES_LIST 游戏清单与常量
│   └── gameMeta.ts      # 元数据补全与合集筛选规则
├── hooks/               # 键盘、游戏循环、本地存储等 hooks
├── App.tsx              # 路由配置
├── main.tsx             # 入口文件
└── index.css            # 全局样式
```

## 🎮 游戏玩法

1. 打开首页，按分类浏览，或进入「合集专题」按场景找游戏
2. 点击游戏卡片进入游戏
3. 按照游戏内提示进行操作
4. 游戏结束后自动保存最高分
